Web App · Live Music & Maps

Giggity - London gigs

I kept hearing about gigs after they had happened or sold out. Giggity collects listings from the Ticketmaster API and independent London venue programmes into a local SQLite store, pauses ambiguous bills for review, tracks real changes without treating missing feed rows as cancellations, and publishes a verified snapshot to a static SvelteKit and MapLibre app on Cloudflare.

Python SQLite Pydantic SvelteKit TypeScript MapLibre Cloudflare
